CallCenter Inventory


System Ewidencji Sprzętu Firmowego


Opis projektu


Aplikacja desktopowa przeznaczona do zarządzania sprzętem firmowym w przedsiębiorstwie z branży call center zatrudniającym około 100 pracowników.


Głównym celem projektu jest usprawnienie procesu ewidencjonowania urządzeń, kontrolowania ich dostępności oraz zarządzania przydziałami sprzętu do poszczególnych pracowników.


Aplikacja ma zastąpić tradycyjne metody prowadzenia ewidencji, takie jak arkusze kalkulacyjne i dokumentacja papierowa.


Główne funkcjonalności


- Zarządzanie ewidencją sprzętu firmowego

- Dodawanie, edytowanie i usuwanie informacji o urządzeniach

- Przypisywanie sprzętu do konkretnych pracowników

- Rejestrowanie zwrotów urządzeń

- Monitorowanie aktualnego statusu sprzętu

- Przeglądanie historii przydziałów i zwrotów

- Zarządzanie listą pracowników

- Wyszukiwanie i filtrowanie urządzeń

- Rejestrowanie informacji o awariach i uszkodzeniach


Wykorzystywane technologie


- Python 3

- Tkinter

- MySQL 8.0

- MySQL Connector/Python

- MySQL Workbench

- Visual Studio Code

- Git i GitHub

- draw.io

Struktura bazy danych


users - dane administratorów systemu

employees - dane pracowników firmy

categories - kategorie sprzętu

equipment - ewidencja urządzeń

assignments - historia przydziałów i zwrotów sprzętu

fault_reports - zgłoszenia awarii i uszkodzeń
